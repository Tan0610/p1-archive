Get the archive back

Paste what was published — the feed owner and topic, or the archive address — and this page finds the newest edition on Swarm and downloads every file, checking each one against its SHA-256. It is a single file with no install. Save it anywhere; it keeps working as long as some Swarm gateway does.

    Everything it does is written down in docs/RECOVERY.md of the archive's repository, and in short here: the topic is keccak256 of its text; update i lives at chunk keccak256(keccak256(topic ‖ uint64_be(i)) ‖ owner); the chunk's payload after 105 bytes of header is an 8-byte timestamp and the 32-byte reference of that edition; /bzz/<reference>/catalogue.json lists every file with its SHA-256.
